## 反例代码（可选，反例类必填）

> 错误写法 vs 正确写法的对比，AI 出码时主动规避左侧、采用右侧。

```diff
- // 反例：在循环里逐条调用 Redis，无 pipeline
- for _, id := range ids {
-     val, _ := redis.Get(ctx, "key:"+id)
-     ...
- }
+ // 正确：批量调用，pipeline / mget 减少 RTT
+ pipe := redis.Pipeline()
+ for _, id := range ids {
+     pipe.Get(ctx, "key:"+id)
+ }
+ res, _ := pipe.Exec(ctx)
```
